# Photo Rationalisation — Version 1

**Decision:** P52.02 DEMOTED FROM A_CORE — DUPLICATE COVERAGE

## Finding

The original P52.02 brief requested a controlled multi-photo defect plate covering travel stain, incomplete sections, pollen/propolis and heat/handling damage.

During final A_CORE reconciliation, Chapter 52 already contains two stronger teaching assets:

1. **Photo 52.1** — a real public-domain Ross Round photograph showing a fully finished centre section beside an unfinished adjacent section.
2. **Figure 52.9 — Comb Honey Defect Atlas** — the canonical PBH-v1 visual covering ten comb-honey presentation, grading and exclusion concerns.

Adding P52.02 as another A_CORE photograph would duplicate incomplete-section teaching while still failing to show every defect with equal provenance and clarity.

## Decision

P52.02 is moved from:

- `A_CORE / SOURCE_OR_CREATE`

to:

- `C_OPTIONAL / OMIT_V1_DUPLICATE_COVERAGE`

This is an editorial rationalisation, not a missing-asset workaround. The photo can be reconsidered in a future edition only if final layout or reader testing demonstrates a specific information gap.
