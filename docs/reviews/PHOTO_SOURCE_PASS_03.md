## Selection rationale

### P39.01 — Healthy Larvae Reference

The selected Commons photograph is a real *Apis mellifera* comb and explicitly documents eggs, young larvae, older larvae, capped brood, hatching and pollen cells. It provides the several-age normal-development context missing from the earlier single-larva candidate.

Source: https://commons.wikimedia.org/wiki/File:HoneyComb.jpg

### P49.02 — Uncapping Detail

The selected photograph directly documents a wooden honeycomb frame being uncapped with a scraping tool before extraction. Resolution is adequate for print. The final crop must preserve safe-handling context.

Source: https://commons.wikimedia.org/wiki/File:Uncapping_honeycomb.jpg

### P58.01 — Royal Jelly in Queen Cell

The selected photograph shows two opened queen cells with Western honey-bee queen larvae floating in royal jelly. The native 1644×1096 file is retained for conservative single-column placement rather than a large spread.

Source: https://commons.wikimedia.org/wiki/File:Weiselzellen_68a.jpg

## Intentionally not selected

### P43.01 — AFB Brood Frame

The candidate has clear reuse rights and visually matches an AFB brood-frame example, but the uploader description alone does not satisfy the handbook rule for confirmed named disease imagery. It remains secondary until diagnostic provenance can be strengthened.

### P52.01 — Premium Comb Honey

The candidate is high-resolution and CC0, but “comb honey” alone does not prove the planned premium grading criteria (fresh, broodless, fully capped). It remains secondary pending editorial inspection.

### P56.01 — Pollen Trap Drawer

The image is high-resolution and public domain, but it is a historical irradiation-research photograph. It demonstrates a pollen-trap drawer, yet a modern clean production photograph remains preferable.
