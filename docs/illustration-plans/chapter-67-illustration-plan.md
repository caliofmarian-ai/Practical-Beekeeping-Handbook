## Accuracy Requirements

- External and internal traceability must be distinguished clearly.
- Final consumers must not be depicted as requiring the same business-customer records in ordinary EU one-step-forward traceability.
- Blend percentages must come from recorded masses and source identity, not inferred visually.
- QR/barcode graphics must not imply the code alone creates traceability.
- Rework and returned stock must retain original history.
- Recall illustrations must show quantity reconciliation, not only customer notification.

## Accessibility

- Use text, arrows and patterns as well as colour.
- Codes must be readable at print scale.
- Flow direction must remain obvious in greyscale.
