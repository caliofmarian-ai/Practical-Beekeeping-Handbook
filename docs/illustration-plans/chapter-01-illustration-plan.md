# Chapter 1 — Introduction to Beekeeping: Illustration Plan

Status: planned for final layout. No provisional artwork is embedded in the manuscript.

## Planned Figures

### Figure 1.1 — The Managed Honey Bee System
Colony, hive, apiary, landscape, beekeeper, products and pollination shown as one connected system.

### Figure 1.2 — What a Colony Contains
Cutaway showing queen, workers, drones when present, brood, pollen, honey and comb without implying fixed positions in every hive.

### Figure 1.3 — The Beekeeping Year at a Glance
Season-neutral circular sequence: colony build-up, reproduction/swarming pressure, surplus collection, preparation, winter/dearth survival.

### Figure 1.4 — Beginner Decision Path
Learn biology → obtain safe equipment → select site → acquire healthy bees → inspect systematically → monitor health → harvest only surplus → keep records.

## Accuracy Requirements
- Use `colony` for the living social unit and `hive` for housing.
- Do not depict one hive type as universally correct.
- Keep seasonal labels adaptable to hemisphere and climate.
