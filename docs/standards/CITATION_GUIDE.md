# Citation Guide

**Project:** Practical Beekeeping Handbook

Version: 1.0

---

# Purpose

Every factual statement that is not common knowledge should be supported by reliable sources.

---

# Preferred Sources

Priority order:

1. Peer-reviewed scientific papers
2. Universities
3. Government publications
4. Official legislation
5. Recognised beekeeping organisations
6. Scientific books

---

# Avoid

Do not use unsupported information from:

- Random blogs
- AI-generated articles
- Anonymous websites
- Marketing material
- Social media posts as evidence

---

# Citation Principles

- Cite the original source whenever possible.
- Prefer recent editions.
- Verify scientific names.
- Check publication dates.
- Preserve technical accuracy.

---

# Updating

References should be reviewed periodically to replace outdated information with newer evidence when appropriate.
