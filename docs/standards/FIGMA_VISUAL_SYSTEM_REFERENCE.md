## Purpose

The Figma file is a visual reference and design-exploration surface for semantic state colours, card grammar, spacing/radius tokens, line-weight roles, canvas-profile examples and future layout experiments.

It does not create a separate Figma style.

## Typography note

The connected Figma environment does not expose Arial. The reference board therefore uses Inter for on-canvas preview text only.

Final publication SVG typography remains Arial, Helvetica, sans-serif.

No Figma-generated asset may enter the book with Inter simply because it was authored in Figma.

## Token authority

Canonical values remain in docs/standards/VISUAL_STYLE_GUIDE.md and docs/standards/VISUAL_FOUNDATIONS_V1.md. Figma variables mirror those values.

## Tool-neutral rule

Canva, Figma, generated SVGs and future commissioned art must all converge to PBH-v1 before publication.
