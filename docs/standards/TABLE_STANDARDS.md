# Table Standards

**Project:** Practical Beekeeping Handbook

Version: 1.0

---

# Purpose

Tables shall present information in a concise, comparable and practical format.

They should simplify complex information rather than repeat the text.

---

# Rules

Every table shall:

- Have a unique number.
- Have a descriptive title.
- Be referenced in the chapter text.
- Use consistent units.
- Be easy to read on both mobile and print.

---

# Numbering

Examples:

Table 1.1

Table 3.2

Table 10.4

---

# Recommended Uses

Tables should be used for:

- Equipment comparisons
- Bee diseases
- Seasonal tasks
- Queen development
- Bee races
- Treatments
- Honey plants
- Production data
- Costs
- Timelines

---

# Quality Checklist

Before publication verify:

- Accuracy
- Consistency
- Readability
- Correct numbering
- Updated data
