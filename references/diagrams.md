## 1. Why Diagrams Need Their Own Register

A photograph can show what something looked like. An illustration can show anatomy or equipment clearly. A diagram answers a different question: **how are things related, what happens next, what decision follows, or how does a variable change?**

The handbook uses diagrams for:

- biological development;
- seasonal dynamics;
- disease/parasite life cycles;
- diagnostic reasoning;
- management decision paths;
- food-processing workflows;
- traceability;
- business economics;
- habitat networks;
- evidence appraisal;
- technology adoption.

A consistent diagram system reduces cognitive load and prevents contradictory visual conventions between chapters.

## 2. Diagram Classes

### D1 — Timeline
Use for development, queen rearing, seasonal events, treatment windows, product preservation, or historical sequences.

**Standard:** time runs left to right unless a circular annual cycle is clearly superior.

### D2 — Decision tree
Use when the reader observes a condition and must choose among next steps.

**Standard:** start condition at top; yes/no or named branches; stop/seek-authority states visually distinct.

### D3 — Process flow
Use for defined operations such as extraction, traceability, sampling, cleaning, or recall.

**Standard:** physical product/material movement uses solid arrows; information/record flow uses dashed arrows.

### D4 — Life cycle
Use for honey bee development, Varroa/Tropilaelaps, pathogens, and pests.

**Standard:** life stages visually distinct and biologically ordered; host stage shown explicitly where relevant.

### D5 — Causal pathway
Use for stress interactions such as Varroa → virus → shortened worker lifespan → colony decline.

**Standard:** arrows mean directional mechanism/effect only when supported; correlation is shown differently.

### D6 — Comparison matrix
Use for hive types, monitoring methods, disease differentials, equipment, insurance, product preservation, or technology choices.

### D7 — Technical cutaway
Use for hive airflow, tracheal mites, extraction equipment, tank layers, comb cells, or processing systems.

### D8 — Landscape/map diagram
Use for forage, apiary positioning, habitat connectivity, movement, or dated pest distribution.

### D9 — Data/chart diagram
Use for scale-hive curves, population cycles, time–temperature quality change, costs, or experimental results.

### D10 — Evidence/system model
Use for HACCP, IPM, research hierarchy, legal/compliance matrix, or future-scenario systems.

## 3. Arrow and Line Conventions

| Visual convention | Meaning |
|---|---|
| Solid arrow | Physical transfer, biological progression, or defined process step |
| Dashed arrow | Information flow, indirect influence, possible route, or record linkage |
| Double-headed arrow | Interaction or reversible exchange; use sparingly |
| Dotted boundary | Conceptual zone, uncertain boundary, or optional system scope |
| Solid boundary | Physical container, hive, defined legal/process unit |
| Red/triangle hazard symbol | Hazard/stop point; must also have text or shape so colour is not required |
| Shield/check symbol | Verified control, not merely “safe” |
| Question diamond | Decision point |
| Rounded terminal | Start/end/stop/escalate state |

No arrow should exist merely because the graphic “looks dynamic”.

## 4. Colour and Accessibility

Colour is secondary to structure.

Recommended semantic families:

- colony/bee biology — warm neutral tones;
- food/product stream — amber/gold family;
- records/data — cool neutral family;
- hazards — high-contrast warning treatment plus symbol/label;
- regulated/authority action — distinct outline and explicit `CHECK CURRENT LOCAL REQUIREMENTS` label;
- environmental habitat — natural green/blue family, still differentiated by pattern/label.

Requirements:

- all diagrams must work in greyscale;
- no red/green-only pass/fail coding;
- font size tested at final print dimensions;
- line weights survive PDF downsampling;
- alt text summarises relationships, not merely colours.

---

## 5. Units and Quantities

- SI/metric units are primary.
- Temperature: °C, with °F only where a regional edition explicitly requires it.
- Mass: g, kg.
- Volume: mL, L.
- Distance: mm, cm, m, km.
- Concentration/quality values: always include units.
- Time: minutes, hours, days, weeks; biological “day X” starts must be defined.
- Mite infestation: state the method and denominator, e.g. mites per 100 adult bees.

A number without a method or unit should never be placed in a scientific diagram.

---

## 6. Uncertainty Conventions

When evidence is approximate or context-dependent:

- use ranges instead of fake precision;
- label curves `conceptual` when not derived from a specific dataset;
- use shaded bands for natural variation;
- date pest-distribution maps;
- mark region-specific thresholds as examples, not universal constants;
- use `possible` rather than `diagnostic` for non-specific signs;
- use `association` instead of causal arrows when causation is not established.

## 8. Reuse and Consolidation Rules

### Reuse directly
Use the same approved diagram when the teaching question is identical. Add a chapter cross-reference rather than redraw.

Good candidates:
- Varroa life cycle;
- colony traceability chain;
- evidence hierarchy;
- honey time–temperature quality concept;
- annual colony cycle.

### Adapt from a master
Use a common master diagram with highlighted subpaths when chapters focus on different parts.

Example:
- master `hive product traceability` diagram;
- Chapter 48 highlights harvest;
- Chapter 50 highlights blending;
- Chapter 67 highlights recall.

### Do not consolidate
Keep separate when simplification would remove important differences.

Examples:
- AFB and EFB disease progression;
- Varroa versus Tropilaelaps reproductive biology;
- food-safety recall versus animal-disease tracing;
- pollen cold chain versus royal-jelly cold chain.

## 9. Decision-Tree Safety Rules

Every decision tree involving health, chemicals, food, or emergencies must include explicit stop/escalation nodes where relevant.

Examples:

- suspected notifiable disease → **STOP MOVEMENT / CONTACT COMPETENT AUTHORITY**;
- severe sting reaction → **EMERGENCY MEDICAL RESPONSE**;
- uncertain chemical contamination → **SEGREGATE PRODUCT / DO NOT BLEND**;
- violent extractor imbalance → **STOP / ISOLATE POWER / WAIT FOR COMPLETE STOP**;
- treatment failure → **DIAGNOSE FAILURE / DO NOT INCREASE DOSE OFF-LABEL**.

## 10. Maps

Maps require a source/date field.

### Stable maps
Can show:
- countries/regions;
- broad climatic context;
- general historical development.

### Dynamic maps
Require explicit publication date/source:
- Tropilaelaps distribution;
- small hive beetle regulated zones;
- disease outbreaks;
- pesticide restrictions;
- organic-certification boundaries if mapped.

Do not freeze a 2026 pest-distribution map into future editions without re-verification.

---

## 11. Data Charts

A chart must state whether it is:

- measured data from a cited study;
- an illustrative worked example;
- a conceptual relationship;
- a simulated scenario.

Measured charts require:
- source;
- sample/population;
- units;
- time range;
- uncertainty where applicable.

Conceptual charts must not use pseudo-precise values that make them appear empirical.

## 13. Diagram Quality Audit

Reject or revise a diagram if it:

- has decorative arrows with no defined meaning;
- uses icons without labels for technical concepts;
- makes one diagnostic sign equal one disease;
- contains a universal threshold not supported by the text;
- uses wrong hive geometry;
- implies treatment reaches capped mites when it does not;
- confuses honey moisture with water activity;
- shows traceability without internal lot links;
- equates managed honey bee abundance with biodiversity;
- turns a model prediction into certainty;
- cannot be read when printed in greyscale.
