# Reference 79 — Useful Websites

This section prioritises official, scientific, regulatory, and high-value technical websites. It is not a directory of commercial suppliers or general beekeeping blogs. Regulatory links are especially time-sensitive and must be checked again before each edition.

Access/update review for this manuscript: September 2026.

## Weather, Mapping, and Phenology

Local weather and plant phenology often matter more than general climate averages. Useful sources include:

- national meteorological services;
- agricultural extension crop-development services;
- verified local weather stations;
- biodiversity/plant-recording schemes;
- the beekeeper’s own multi-year bloom and hive-scale records.

Never use a generic flowering calendar as if it were valid for every altitude, latitude, cultivar, or year.

## How to Judge a Beekeeping Website

Prefer a website when it provides:

1. identifiable institution or authorship;
2. publication/update date;
3. references or evidence trail;
4. clear jurisdiction;
5. distinction between law and advice;
6. current product/medicine information where relevant;
7. correction or update mechanisms.

Be cautious when a page:

- gives a fixed treatment recipe without jurisdiction or product label;
- claims one visible sign proves a disease;
- uses “natural” as proof of safety;
- sells the same remedy it claims solves every problem;
- presents testimonials as clinical evidence;
- makes disease-treatment claims for foods/supplements without regulatory basis;
- has no date despite discussing fast-changing law or medicine authorisation.

## Link-Maintenance Rule

Before final publication and before each new edition:

- test every URL;
- replace redirected legacy links with current institutional landing pages;
- verify the page still belongs to the stated organisation;
- record the current access date for legal/regulatory resources;
- prefer a durable institutional home page when deep links change frequently;
- never preserve a dead link merely because it appeared in an earlier edition.
