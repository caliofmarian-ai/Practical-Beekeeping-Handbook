# Reference 81 — Tables

This section consolidates the most useful lookup tables from the handbook into one reference location. It does not replace the explanatory chapters. Values that depend on law, climate, product authorisation, or regional thresholds are deliberately identified as context-dependent.

## Table 81.1 — Honey Bee Development: Typical Timelines

| Caste | Egg | Larva before capping | Capped development | Typical emergence from egg |
|---|---:|---:|---:|---:|
| Queen | ~3 days | ~5–6 days | ~7–8 days | ~16 days |
| Worker | ~3 days | ~6 days | ~12 days | ~21 days |
| Drone | ~3 days | ~6–7 days | ~14–15 days | ~24 days |

**Use:** planning queen rearing, brood assessments, splits, and emergence timing.

**Caution:** biological development varies with temperature, genetics, nutrition, and colony conditions. These are standard practical approximations, not exact clocks.

## Table 81.4 — Colony Emergency Priorities

| Finding | Immediate priority | Avoid |
|---|---|---|
| Active starvation | Put safe accessible food at cluster | Long cold inspection |
| Severe robbing | Remove exposed feed/honey; reduce defensible entrance | Open supers and spilled syrup |
| Transport overheating | Restore ventilation/shade | Sealing populous hive without airflow |
| Storm-opened hive | Reassemble, weatherproof, stop honey exposure | Randomly moving comb among colonies |
| Sudden mass mortality | Preserve evidence and investigate | Discarding all dead bees before sampling |
| Suspicious brood disease | Stop transfers; isolate tools; seek confirmation | Strengthening other colonies with suspect brood |
| Flooding | Protect people first; move only if safe | Entering dangerous floodwater |

## Table 81.5 — Queen Problem Differential

| Observation | Important possibilities |
|---|---|
| No eggs, no young larvae | Queenlessness, brood break, newly introduced/virgin queen, recent swarm |
| Small irregular worker-brood area | Failing queen, disease, nutrition, chilled brood, Varroa-associated loss |
| Multiple eggs/cell, drone brood in worker cells | Laying workers or occasionally inexperienced newly laying queen |
| Repeated supersedure cells | Queen quality/age, injury, colony response |
| Queen present but little brood | Season, nutrition, queen failure, disease/parasites, brood-space restriction |

## Table 81.6 — Brood Disease / Stress Differential

| Sign | Main differentials | Confirmation principle |
|---|---|---|
| Patchy brood | AFB, EFB, Varroa, queen failure, chilled brood, nutrition, hygienic removal | Examine individual cells + history; sample if suspicious |
| Sunken/perforated capped cells, brown remains | AFB among important possibilities | Stop transfer and obtain competent confirmation |
| Twisted yellow/brown open larvae | EFB, chilling, other larval disorders | Field/lab confirmation as needed |
| White/grey/black mummies | Chalkbrood | Characteristic mummies + colony context |
| Sac-like larvae | Sacbrood | Pattern + laboratory confirmation if atypical |
| Uncapped pupae/deformed adults | Varroa-associated viral damage, hygienic removal | Quantify Varroa; assess virus/disease context |

## Table 81.8 — Major Honey Bee Parasites

| Parasite | Location | Key biological feature | Practical detection |
|---|---|---|---|
| *Varroa destructor* | Adult bees + capped brood | Reproduces in capped brood; feeds on host tissues; major virus vector | Validated adult-bee sample; brood/natural-fall methods as supporting tools |
| *Tropilaelaps* spp. | Mainly brood-associated | Rapid reproduction, strong brood dependence, emerging range | Brood examination, mite fall, adult sampling, official/molecular confirmation |
| *Acarapis woodi* | Adult thoracic tracheae | Microscopic internal mite | Tracheal dissection or validated lab method |

## Table 81.9 — Varroa Monitoring Methods

| Method | Main use | Bees sacrificed? | Main limitation |
|---|---|---|---|
| Alcohol/detergent wash | Quantitative adult-bee infestation estimate | Yes | Queen must be excluded; technique/sample matter |
| Sugar roll | Non-lethal estimate | Usually no | Humidity and technique affect performance |
| Natural mite fall | Presence/trend/treatment drop | No | Not always a direct substitute for adult-bee infestation |
| Brood uncapping | Reproduction/presence in brood | Brood destroyed locally | Weak as sole whole-colony threshold measure unless protocol validates it |

**Calculation:** `mites per 100 bees = (mites recovered ÷ bees sampled) × 100`.

**Threshold rule:** use current regional guidance; do not treat one number as universal.

## Table 81.12 — Nectar Flow: Observation to Decision

| Observation | Interpretation | Management response |
|---|---|---|
| Flowers abundant, hive weight flat | Source may be weak or colony unable to exploit it | Check bee visitation, weather, colony strength |
| Sustained multi-day gain | Useful flow active | Provide storage space before congestion |
| Strong daytime gain, large overnight loss | Dilute nectar being ripened | Do not equate gross gain with final honey mass |
| Fresh white wax + rapidly filling supers | Strong intake/construction | Add space appropriately |
| Weight declines after bloom | Dearth/consumption | Protect stores; control robbing |
| Sudden large loss | Swarm or management event | Investigate immediately |

## Table 81.13 — Harvest Readiness

| Finding | Interpretation | Action |
|---|---|---|
| Mostly capped; representative moisture comfortably within specification | Mature crop likely | Harvest if treatment/colony-store checks pass |
| Many uncapped cells; low uniform measured moisture | Could be mature but uncapped | Harvest may be acceptable within quality system |
| Many uncapped cells; variable/high moisture | Uneven ripening | Delay or segregate wet frames |
| Brood in super | Not ordinary harvest comb | Segregate brood frame |
| Treatment withdrawal incomplete | Legal/food-safety restriction | Do not harvest affected honey for sale |
| Chemical/flood/fire taint suspected | Possible contamination | Segregate and obtain competent assessment |

## Table 81.14 — Honey Quality Parameters

| Parameter | What it helps assess | What it does not prove alone |
|---|---|---|
| Moisture | Fermentation risk, composition, storage margin | Authenticity |
| Water activity | Microbial water availability | Total composition/origin |
| HMF | Heat/storage history indicator | Exact heating history or syrup addition |
| Diastase | Enzyme status affected by source/heat/age | Exact age or authenticity |
| Conductivity | Broad honey-type/mineral classification | Exact botanical origin |
| Free acidity | Composition/fermentation clues | Cause of high acidity alone |
| Sugar profile | Composition and some authenticity/origin clues | Every fraud type |
| Pollen | Botanical/geographical support | Exact nectar percentage without expert interpretation |
| Stable isotopes | Some exogenous sugar adulteration | Every adulteration route |
| NMR / MS fingerprint | Broad authenticity/origin patterns | Certainty without valid reference data |

## Table 81.15 — Selected EU Honey Composition Examples (Check Current Law)

The following are examples from the current EU honey framework during the 2026 manuscript cycle. They are **not universal global operating targets**.

| Parameter | General EU example | Important caveat |
|---|---|---|
| Moisture | ≤20% for honey in general | Named exceptions exist (e.g. heather/baker’s honey categories) |
| Free acidity | ≤50 meq/kg in general | Baker’s honey differs |
| Conductivity | Often ≤0.8 mS/cm for many blossom honeys | Honeydew, chestnut, and named botanical exceptions differ |
| Diastase | Generally ≥8 Schade | Naturally low-enzyme honey exception exists with low HMF condition |
| HMF | Generally ≤40 mg/kg after processing/blending | Tropical-origin exception exists |

**Before printing:** verify consolidated EU Directive 2001/110/EC and current national transposition.

## Table 81.16 — Extraction Equipment: Main Trade-offs

| Equipment | Strength | Limitation |
|---|---|---|
| Tangential extractor | Supports fragile comb; effective on viscous honey | Frames need turning/reversal; slower |
| Radial extractor | High capacity; both sides extract in normal cycle | Fragile/very viscous comb can still be difficult |
| Manual drive | Simple; low cost; direct speed feel | Labour/time |
| Motorised drive | Throughput, repeatability, automation | Electrical/mechanical hazards and cost |
| Coarse strainer | Removes wax/debris with minimal product alteration | Does not create polished ultra-clear product |
| Fine filtration | Removes finer material | Can clog, require warming/pressure, and may alter pollen content/product category |

## Table 81.17 — Honey Storage Changes

| Observation | Likely issue | Response principle |
|---|---|---|
| Fine uniform crystallisation | Normal physical change | Accept if product specification permits |
| Coarse crystals | Texture defect | Controlled re-liquefaction/rework if otherwise sound |
| Liquid layer over crystals | Phase separation | Check moisture by phase/lot; assess fermentation risk |
| Gas + alcoholic/sour odour | Fermentation likely | Segregate; do not release as ordinary table honey |
| High-temperature history | HMF/enzyme/aroma risk | Review duration; test if needed |
| Missing lot label | Traceability failure | Quarantine until identity is resolved |

## Table 81.18 — Hive-Product Preservation Priorities

| Product | Main stability risk | Typical preservation principle |
|---|---|---|
| Honey | Moisture, heat, fermentation, contamination | Dry sealed storage; controlled temperature |
| Comb honey | Heat-softened wax, storage pests, odour | Cool protected packing; validated physical pest control |
| Beeswax | Heat/fire, odour, residues/adulteration | Clean source separation; cool dry storage |
| Bee pollen | High moisture/microbial growth | Rapid freezing or validated drying; sealed storage |
| Propolis | Oxidation, contamination, solvent/product stability | Clean collection; cool/dark storage; defined extraction system |
| Royal jelly | Rapid biochemical deterioration | Strict cold chain / freezing or validated preservation |
| Bee venom | Moisture, contamination, allergen exposure | Dry controlled storage; specialist safety/quality system |

## Table 81.25 — Scientific Evidence Appraisal

| Question | Stronger evidence indicator |
|---|---|
| Was there a control group? | Appropriate contemporaneous control |
| Randomisation? | Allocation not chosen by investigator/condition |
| Replication? | Multiple independent colonies/apiaries, not only many bees from one colony |
| Effect size reported? | Magnitude + confidence interval, not only p-value |
| Field relevance? | Conditions resemble intended management context |
| Repeated independently? | Multiple research groups/locations |
| Review evidence? | Systematic review/meta-analysis or guideline synthesis |
| Product/legal fit? | Intervention authorised and operationally applicable |
